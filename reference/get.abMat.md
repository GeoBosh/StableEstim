# Default set of parameters to pass to [`Estim_Simulation`](https://geobosh.github.io/StableEstim/reference/Estim_Simulation.md)

Default set of parameters to pass to
[`Estim_Simulation`](https://geobosh.github.io/StableEstim/reference/Estim_Simulation.md),
inspired by the one used by Koutrevelis (1980) in his simulation
procedure.

## Usage

``` r
get.abMat()
```

## Value

a 2-columns matrix containing a wide range of parameters \\\alpha\\ and
\\\beta\\ covering the entire parameters space.
